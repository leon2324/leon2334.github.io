Dual Flagship Projects

雙旗艦專案：理論、工程與田野的深度交織

結合認知心理學核心模型，以軟體工程打破法律資訊壁壘，以田野伴讀重塑過動學童的學習自信。

FLAGSHIP 01 · 科技實踐 Flutter / Clean Architecture Paivio 雙重編碼理論 憲法訴訟法第127條合規

《緒言 Preamble》法律條文閱讀輔助 App

以認知心理學降低法規閱讀的工作記憶超載，榮獲 MAIC 行動應用創新賽等技術榮譽

💡 認知心理學理論根基
Baddeley 工作記憶模型 (Working Memory Model) 與 Paivio 雙重編碼理論 (Dual-Coding Theory)：
傳統法律條文具備高度巢狀的法條結構與密集文字，對非法律專業民眾構成嚴重的「外在認知負荷 (Extraneous Cognitive Load)」。《緒言》透過將法條關係空間結構化、引入 Bento Grid 模組切割（Chunking），讓讀者在視覺畫布與語音迴路同步解碼，降低大腦內部負載，提升 38% 理解效率。
⚙️ 現代軟體架構實踐
基於 Flutter 跨平台框架 與 Clean Architecture 架構規範：
  • ✓ 分層解耦：嚴格區隔 Domain Entities、Repository 介面與 Presentation 視圖，確保程式碼高度可維護性與單元測試覆蓋。
  • ✓ 無障礙合規：嚴格依循《憲法訴訟法》第 127 條法條格式規範進行版面流式排版，支援視障高對比度閱讀模式。
  • ✓ 離線本地索引：整合嵌入式 SQLite 本地全文索引引擎，在完全無網環境下亦能以毫秒級速度精準索引全國法規資料庫。

FLAGSHIP 02 · 田野實踐 行為消退法 (Extinction) 15分鐘微進度條注意力錨定 高雄市立圖書館三和分館

ADHD 過動兒童伴讀田野實踐 (Field Tutoring)

將行為心理學轉化為有溫度的陪伴：從衝動對抗到重建學習自我效能感

🌿 心理學理論介入策略
在社區與圖書館長達數百小時的一對一伴讀中，面對經常撕講義、摔筆、言語挑釁的重度注意力不足過動症 (ADHD) 學童：
  • ✓ 行為消退法 (Behavioral Extinction)：對於學童刻意引發注意的挑釁行為，採取「冷靜、不給予情緒強化」的態度，消退其破壞性行為的次級增強機制。
  • ✓ 前導提示 (Prompting) 與微進度條注意力錨定：針對 ADHD 兒童工作記憶短暫、無法承受長時目標的特性，自創「15 分鐘微任務進度條」，將整頁考卷切分為 3 個微單元，達成即畫上微獎勵標記。
  • ✓ 系統性焦慮反思：深入洞察其衝動行為背後實為「對學業失敗的巨大恐懼」，透過建立微成功經驗，協助學童在學期末自主坐定完成評量，重建自我效能感 (Self-Efficacy)。
💬 田野反思摘錄（送審自傳精選）

「當我不再把他的分心看作『不聽話』，而是看作『大腦工作記憶超載引發的保護性逃避』時，真正的溝通才開始發生。教育不是強壓規則，而是為他建造一條可以一步一步跨過去的認知階梯。」

PAPER 01 社會心理學 · 青少年發展

《同儕從眾壓力對青少年自我效能感之影響——以 Asch 實驗為理論基礎》

以古典 Asch 從眾範式為核心，探討中學生在同儕團體規範約束下對自我認知效能的折損效應。論文進一步結合非學校型態自學者經驗，論證自主學習如何透過脫離無效從眾壓力，重構學習內在動機與自我調節能力。

理論基礎：Solomon Asch / Bandura 已收錄於送審論文集
PAPER 02 認知心理學 · 人機交互 (HCI)

《由 Baddeley 工作記憶模型看法律條文呈現方式對理解效率之影響——《緒言》App 介面設計實驗》

結合 HCI 實驗設計，招募受試者進行法律條文閱讀與回憶測試。量化數據實證：採用雙重編碼空間排版與 Bento 模組切分，能使讀者在無效認知負荷指標上降低 38%，並顯著提升法律專有名詞之長時記憶提取精準度。

理論基礎：Baddeley / Paivio / Sweller 已收錄於送審論文集
PAPER 03 比較法學 · 司法數位轉型

《日本2026年民事訴訟全盤IT化歷程對台灣司改之啟示——比較法視角》

運用 JLPT N1 日語研究能力，直接研讀日本法務省、最高裁判所第一手公報與判例。深入分析日本「民事訴訟法改正案」e-Filing、e-Courtroom、e-Case Management 三階段改革進程，探討其對我國電子訴訟制度與弱勢訴訟權之借鏡價值。

SPECIAL MONOGRAPH · 軟體架構實踐哲學

《從 Vibe Coding 到系統工程：自學者的 AI 協同開發實踐哲學》
